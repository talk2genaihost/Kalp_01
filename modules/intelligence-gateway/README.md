# KALP Intelligence Gateway — Phase 1

Provider-neutral shared intelligence layer for KALP applications.

## Phase 1 policy
- Free-first / trial-first
- Gemini: primary reasoning provider
- OpenRouter: free-model fallback/router
- Groq: fast fallback
- Research retrieval remains separate from model reasoning
- Provider keys remain server-side

## Consumers
The gateway is intended to serve AdManthan first and later other KALP applications such as MarketManthan, KALP News, Genie and future projects.

## Status
Working implementation. This document does not promote the gateway to canonical KALP architecture.
