# 01 — System Overview

KALP is not a chatbot, a single model, a vector database, an agent framework alone, a memory product,
a workflow engine alone, Genie itself, or a replacement for domain applications.

It is the governed substrate beneath domain systems.

## Reference architecture
Experiences / Applications
↓
API and workflow boundary
↓
KALP Agent Runtime — plan, execute, delegate, verify, checkpoint, recover
↓
KALP Core | Smriti | Governance
↓
Models / Tools / Connectors
↓
Infrastructure / Data / SRE
