# 02 — Nine-Part Reference Architecture

A. Constitution & Contracts — principles, invariants and canonical contracts.
B. Technical Architecture & Runtime — service and runtime boundaries.
C. Data, APIs & Smriti — canonical objects, schemas and event semantics.
D. Agent Runtime, SDK & Swarm — lifecycle, delegation, execution and recovery.
E. Security, Identity, Policy & Governance — trust and control plane.
F. Learning & Intelligence Evolution — feedback, validation and rollout.
G. Observability, Reliability & Operations — assurance, SRE, DR and testing.
H. Experience & Ecosystem — Genie, DADI, Marketing, Enterprise/SAP and future applications.
I. Integration & Implementation Roadmap — dependency order, vertical slices and delivery gates.

Constitution governs all layers. Canonical contracts define shared semantics. Runtime implements execution.
Security and governance may constrain every path. Learning improves behavior only within governance.
Applications consume KALP; they do not redefine KALP.
