# Persona Intelligence and Governance

Primary authority:
17-Point Story-Based Persona Assessment

Evidence chain:
Story evidence → Observed behavior → Recurring pattern → 17-point assessment → Character DNA

Generic profiles, bios, HR/persona sheets, visual boards and surface traits are supporting references and cannot override the 17-point assessment.

Persona runtime concepts:
- Persona DNA
- Authority scope
- Cognitive role
- Capability matrix
- Behavioral rules
- Communication style
- Memory scope
- Performance/voice identity where applicable

Persona ≠ Provider ≠ Model.
