# Smriti — Governed Memory Architecture

Memory is governed by:
Relevance • Confidence • Scope • Source • Freshness

Operational layers:
- Working Memory
- Session Memory
- Project Memory
- Persona Memory
- System / Shared Memory
- Long-Term Memory

Governance scopes:
Local Task → Project → Client/Domain → Organizational → Canonical

Memory Gatekeeper decisions:
Store? Update? Replace? Merge? Promote? Discard?

Promotion requires validated learning, provenance and versioning.
