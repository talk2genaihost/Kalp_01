# KALP Hive

Shared coordination substrate:
- Agent Registry
- Per-agent Workspace
- Inbox / Outbox
- Shared Blackboard
- Task Ledger / Task Graph
- Event Store
- Runtime State

Recommended lifecycle:
Request → Cognitive Swarm → Persona Activation → Delegation → Task → Execution → Verify → Audit

The Hive pattern was informed by the previously analyzed Munder Difflin runtime design, but KALP does not adopt its identity model.
