# KALP Constitution — Engineering Baseline

Core invariants:
1. Context over data.
2. Relevance over volume.
3. Confidence over guessing.
4. Validation over assumption.
5. Learning over repetition.
6. Governance over freedom.
7. Higher authority governs within scope.
8. A narrower authoritative source may override a broader source only within explicit scope.
9. Do not silently merge unresolved conflicts.
10. Inference must never be promoted as retrieved or canonical state.
11. Applications do not redefine the KALP substrate.
12. Learning must pass governance and validation before promotion.
