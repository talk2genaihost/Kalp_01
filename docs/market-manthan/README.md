# Market Manthan

**Project ID:** MM-001  
**Workspace:** KALP Development Studio

## Purpose
Market Manthan is the standalone market-intelligence and decision-support engine.

## Architecture baseline
Provider Sources → Provider Adapter Framework (PAF) → Manthan/Fusion → Consultant Screen

## Confirmed scope
- Provider Adapter Framework (PAF)
- Manthan/Fusion Intelligence
- Consultant Screen
- Structured confidence and data-quality visibility
- Provider conflict preservation
- Feedback capture

Market Manthan is separate from the broader KALP ecosystem. This project does not create trading or execution authority unless a separate explicit specification is supplied.
